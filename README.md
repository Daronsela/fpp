# Чувак Червяк — приложение для Windows

Три ваших страницы в одной программе с собственным окном: **Учебная папка**, **Нейро-нора** и игра **«Угадай флаг»**.
Все функции сохранены, внешний вид тот же. Работает без интернета.

## Как получить установщик (.exe)

Нужен только [Node.js](https://nodejs.org) (версия LTS) и интернет на время сборки.

1. Распакуйте архив.
2. Дважды щёлкните **`build-windows.bat`**. Первый раз это несколько минут: скачивается Electron.
3. В папке `dist` появятся:
   - `ChuvakChervyak-Setup-1.0.0.exe` — установщик (ярлыки на рабочем столе и в меню «Пуск»);
   - `ChuvakChervyak-Portable-1.0.0.exe` — портативная версия, ставить не нужно.

Хотите просто запустить без сборки: **`run.bat`**.

Нет желания ставить Node.js? Загрузите папку на GitHub, откройте вкладку Actions → «Сборка для Windows» → Run workflow. Готовый `.exe` скачаете из результатов сборки.

## Что внутри

| Раздел | Файл | Горячие клавиши |
|---|---|---|
| Учебная папка (стартовая) | `app/index.html` | `Ctrl+1` |
| Нейро-нора | `app/neuro-nora.html` | `Ctrl+2` |
| Угадай флаг | `app/flags.html` | `Ctrl+3` |

Баннеры внутри страниц работают как раньше, но открывают раздел в том же окне. Назад: `Alt+←` или боковая кнопка мыши. Меню скрыто, оно появляется по нажатию `Alt`. Там же масштаб (`Ctrl` и `+` / `-`) и полноэкранный режим (`F11`).

Ссылки на сайты нейронок и ссылки из конспектов открываются в вашем обычном браузере, поэтому вы остаётесь залогинены.

## Где хранятся данные

В `%APPDATA%\ChuvakChervyak` (меню «Файл» → «Открыть папку с данными»): материалы, загруженные файлы, рекорды, избранные нейронки, маскот. При обновлении или переустановке программы данные остаются.

**Важно:** данные из браузерных версий (материалы и файлы, которые вы добавляли на страницы) в приложение сами не переезжают. Браузер хранит их в своём профиле. Файлы придётся добавить заново («Импорт папки» это делает за раз).

## Что изменено по сравнению с веб-версиями

- Шрифты (Onest, Pixelify Sans) и библиотеки просмотра docx/xlsx/pptx/zip лежат внутри программы, а не грузятся из интернета.
- Тексты про «браузер» и «сайт» заменены на «приложение».
- Кнопка «В новой вкладке» стала «В новом окне».
- Добавлено: контекстное меню (копировать/вставить), запоминание размера и положения окна, один запущенный экземпляр, нативное меню.

## Если что-то пошло не так

- **`Cannot create symbolic link` при сборке** — известная особенность electron-builder в Windows. Включите «Режим разработчика» (Параметры → Для разработчиков) или запустите `build-windows.bat` от имени администратора.
- **Windows SmartScreen пишет «Неопознанный издатель»** — установщик не подписан сертификатом (он платный). «Подробнее» → «Выполнить в любом случае».
- **Просмотр docx/xlsx не работает** — выполните `npm install` ещё раз: библиотеки копируются в `app/vendor` при установке.
- Нужны логи: `npm run dev` откроет окно с инструментами разработчика.

## Для разработчика

`npm test` — проверки главного процесса (протокол `app://`, защита от выхода из папки, правила открытия окон и ссылок, меню).
Electron зафиксирован на 33.x ради повторяемой сборки; обновить: `npm i -D electron@latest`.
